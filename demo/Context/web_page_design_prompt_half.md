# RESPONSIVE VISUAL RULES

At mobile widths:

- Remove large desktop whitespace where necessary
- Stack hero text and photograph
- Heading scales down but remains dominant
- Buttons may wrap
- Cards become full width
- Statistics become two-column or one-column depending on available width
- Expertise becomes one column
- Preserve card border/radius treatment
- Maintain the same color system
- Keep section labels and numbering

The mobile design should feel like the same website, not a separate redesign.
